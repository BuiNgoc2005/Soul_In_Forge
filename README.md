
# Soul in Forge (Prototype)

## Giới thiệu
Game mô phỏng rèn đồ 2D, người chơi nhận nhiệm vụ và chế tạo item.

## Các hệ thống chính
- Inventory System
- Crafting System
- Interaction System
- Level & EXP System

## Vai trò của tôi
- Thiết kế gameplay cơ bản
- Implement Inventory và Interaction
- Xây dựng hệ thống level

## Công nghệ
- Unity
- C#

## Trạng thái
Prototype (chưa hoàn thiện)
